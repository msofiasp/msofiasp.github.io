Overview

Background

Ensuring fair and reliable elections is essential for achieving SDG 16: Peace, Justice, and Strong Institutions. Ballot errors such as overvotes and undervotes affect election accuracy and may indicate issues in ballot design, voter understanding, or precinct-level management.

Previous research has shown that ballot characteristics — including length and number of candidates — significantly influence the likelihood of voting errors. Understanding these patterns can help improve electoral integrity.

🗳️

Research Focus

This study analyzes ballot error rates in the 2025 Philippine Midterm Elections using precinct-level electoral data from 92,745 precincts nationwide.

Research Questions

Q1 📍

Are ballot error rates significantly different across Philippine regions?

Q2 🗳️

Are ballot error rates higher in multi-candidate senatorial ballots vs. party-list?

Q3 👥

Does the number of registered voters per precinct influence ballot error rates?

Hypotheses

H₁

Ballot error rates differ significantly across Philippine regions.

H₂

Senatorial ballots exhibit higher error rates than party-list ballots.

H₃

The number of registered voters per precinct is significantly associated with ballot error rates.

Dataset Description

This project uses two 2025 Philippine Midterm Election datasets containing precinct-level electoral data — registered voters, actual voters, overvotes, undervotes, valid votes, and vote counts per candidate for senatorial and party-list races.

The senate dataset contained 92,822 rows and 78 columns; the party-list, 92,822 rows and 167 columns. Seventy-seven precincts with zero voters were removed, resulting in 92,745 rows.

Dataset Repository

Full datasets (Google Sheets XLSX) are available below:

Dataset 1 — Senate Dataset 2 — Party-list

Data Collection Process

The datasets were published by Vianney Tumbagahan on Figshare using a scraping script by Prof. Christian Alis (AIM). Version 2 was used, updated to account for 23 missing election returns. No sampling was applied — the dataset contains complete precinct records.

Dataset Inspection

CSV files were loaded using Python Pandas. General info of both datasets was checked using info().

Duplicate Checks

Used duplicated().sum() to check for duplicates. No duplicate rows or machineID entries were found.

Removal of Zero Voters

Rows with actualVoters = 0 (77 precincts) were removed to prevent division-by-zero when computing error rates.

Consistency Checks

All actual voters verified to be ≤ registered voters. No precinct had zero registered voters.

Ballot error rate: overVotes / actualVoters

Exploratory Data Analysis

Key notes: overVotes counts excess selections — one voter can contribute multiple overvotes. Precincts with error rate > 1 were excluded from visualizations. OAV and LAV precincts were also excluded due to non-standard sizes.

RQ1 — Ballot Error Rates Across Philippine Regions

Ballot error rates differ significantly across Philippine regions, indicating regional variation in voting behavior and ballot handling.

RQ2 — Senate vs. Party-list Error Rates

Senatorial ballots consistently exhibit higher error rates compared to party-list ballots, suggesting ballot complexity increases voting errors.

RQ3 — Registered Voters vs. Error Rate

Most precincts cluster within a similar range. A slight upward trend exists but the relationship is weak — precinct size alone does not strongly predict voting errors.

Nutshell — Senatorial Ballots Consistently Show Higher Error Rates

Across all regions, senatorial ballots have higher error rates than party-list ballots. Party-list rates are generally low and uniform, while senatorial rates are higher and more variable.

05

Discussion

RQ1

Regional Differences

Significant differences across regions (H = 9450.76, p < 0.001) suggest that voter behavior, ballot handling, and election administration are not uniform. Regions with higher error rates may reflect unequal access to electoral resources or voter education.

Limitation: Underlying causes aren't directly measured. Future work should incorporate demographic and socio-economic variables.

RQ2

Senate vs. Party-list

Significant difference (U = 8.32×10⁹, p < 0.001) between ballot types. Senatorial ballots require selecting multiple candidates from long lists, increasing overvoting risk. This highlights the importance of voter-friendly design and education for first-time and elderly voters.

Limitation: Only overvote-based error rates were examined. Spoiled ballots and ballot abandonment warrant future study.

RQ3

Precinct Size

Weak positive correlation (ρ = 0.104, p < 0.001) shows precinct size has minimal practical influence. Ballot complexity and voter familiarity are more important factors than population size.

Limitation: Staffing levels, machine efficiency, and voter demographics were not included. Future research should cover broader determinants.

06

Machine Learning Modelling

ml_results.py — output

Model

Ridge Regression was used to examine whether ballot type and voter population size influence ballot error rates. L2 regularization improves stability and reduces overfitting.

Hyperparameter Tuning

GridSearchCV with 5-fold cross-validation selected optimal α = 0.1. The model achieved R² = 0.929, explaining ~92.9% of variance in regional ballot error rates.

Key Findings

Ballot type was the strongest predictor — senatorial ballots linked to ~22.2 pp higher error rates (coeff = 0.2221). Registered voters had minimal effect (coeff = 0.0054, p = 0.035).

Limitations & Future Work

Only 36 regional observations used. Model excluded education, socio-economics, layout factors. Future studies may use precinct-level models and random forests or decision trees.

07

Conclusion

This study examined ballot error rates in the 2025 Philippine Midterm Elections using EDA and machine learning. Senatorial ballots produced significantly higher error rates, confirming that ballot complexity strongly influences voting mistakes. Significant regional differences were found, while precinct size showed only a weak relationship.

These results highlight the importance of voter-friendly ballot design, accessible election systems, and effective voter education. Reducing ballot complexity and improving voter guidance may help minimize errors and strengthen democratic participation.

Data science methods can identify patterns in electoral behavior and support evidence-based improvements in democratic processes — helping Filipinos become more informed participants in elections.

Recommendations

📋

Improve ballot layouts to be easier to understand, especially for complex senatorial ballots.

🎓

Strengthen voter education campaigns to better prepare citizens for the voting process.

♿

Prioritize accessibility features and clearer voting instructions to reduce confusion.
