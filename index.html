Ballot Blunders

A Statistical Analysis of Ballot Error Rates in the 2025 Philippine Midterm Elections

Understanding voting errors to support transparent and reliable elections.

Overview

Background

Ballot errors such as overvotes and undervotes can affect election accuracy and may indicate issues in ballot design or voter understanding.

Research Questions

  • Do ballot error rates vary across regions?
  • Are senatorial ballots more error-prone?
  • Does precinct voter size affect error rates?

Proposed Solution

Statistical analysis of precinct-level election data to identify factors influencing ballot error rates.

Hypothesis

  • Regional differences exist
  • Senatorial ballots have higher errors
  • Precinct size influences errors

Data Collection

Dataset Overview

Precinct-level datasets containing registered voters, actual voters, overvotes, undervotes, and candidate vote counts.

Data Collection Process

Data sourced from COMELEC and published through Figshare. Version 2 dataset was used to correct missing election returns.

Data Analysis

Load datasets using Pandas
