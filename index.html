Ballot Blunders

A Statistical Analysis of Ballot Error Rates in the 2025 Philippine Midterm Elections

Exploring patterns of voting errors using precinct-level election data to support transparent, reliable, and data-driven electoral processes.

Aligned with SDG 16 — Peace, Justice, and Strong Institutions

Overview

Background

Fair elections are essential for maintaining strong democratic institutions. However, ballot errors such as overvotes and undervotes can affect the accuracy of election results and may reflect issues in ballot design, voter understanding, or precinct-level election management.

Previous studies suggest that ballot characteristics, such as the number of candidates and ballot length, influence the likelihood of voting errors. Understanding these patterns helps identify factors affecting electoral reliability.

Research Questions

  • Do ballot error rates differ significantly across Philippine regions?
  • Are ballot error rates higher in senatorial ballots compared to party-list ballots?
  • Is the number of registered voters per precinct associated with ballot error rates?

Proposed Solutions

This study applies statistical analysis to examine relationships between ballot design, precinct characteristics, and error rates. The findings aim to provide evidence that may support improvements in election processes and ballot design.

Hypotheses

  • Ballot error rates vary significantly across Philippine regions.
  • Senatorial ballots produce higher error rates than party-list ballots.
  • Precinct voter population significantly influences ballot error rates.

Data Collection

Dataset Overview

The study uses two datasets from the 2025 Philippine Midterm Elections containing precinct-level electoral data including registered voters, actual voters, overvotes, undervotes, valid votes, and vote counts per candidate.

Both senatorial and party-list datasets contain 92,822 precinct records. After removing precincts with zero voters, the final dataset contains 92,745 rows.

Data Collection Process

The datasets were published by Vianney Tumbagahan on Figshare using a scraping script created by Professor Christian Alis. The original data were sourced from the official COMELEC election results website.

Version 2 of the dataset was used, which corrected missing election returns caused by an earlier scraping script bug.

Data Analysis

Data Preprocessing

  • Loaded CSV datasets using the Python Pandas library.
  • Checked dataset structure and column information.
  • Verified that no duplicate precinct entries exist.
  • Removed 77 precincts with zero voters to prevent division errors.
  • Confirmed that actual voters never exceeded registered voters.
  • Calculated turnout rate and ballot error rate for each precinct.
  • Exported cleaned datasets and summaries for further analysis.
