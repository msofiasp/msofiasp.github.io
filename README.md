# Ballot Error Analysis Website

This repository contains a research website analyzing ballot error rates in the 2025 Philippine Midterm Elections.

## SDG Alignment
SDG 16: Peace, Justice, and Strong Institutions

## Research Questions

1. Are ballot error rates significantly different across regions?
2. Are senatorial ballots more error-prone than party-list ballots?
3. Does precinct size affect ballot errors?

## Dataset
2025 Philippine Midterm Elections Dataset  
Source: Vianney Tumbagahan (Figshare)
